   Play Console Data safety and store listing fields. The current in-app

   before promoting live leads. Until then the app explicitly stores demo
   inquiries on-device; they are not delivered to a seller.
4. Verify the FCM V1 credential and test one real push notification through
   the scheduled `price-drop-alerts` worker before promoting price alerts.
   The AI search Edge Function also needs a provider key; local parsing
   remains the fallback.
5. Verify Google/phone login, deep links, maps, shortlist invitations, and
   account deletion on physical Android devices. Test Liquid Glass on iOS
   hardware or simulator separately. English localization is still partial;
   on an English-system device some detail and inquiry copy remains Indonesian.
6. Triage the 32 current `npm audit --omit=dev` advisories (21 high,
   11 moderate) against supported Expo SDK 57 versions. The automatic fixes
   propose incompatible major-version downgrades; no forced fix was applied.
7. Run the local database RLS suite when Docker Desktop is available; its
   engine was not running on this Windows host. The live Supabase migrations,
   scheduled responses, and advisors were checked directly, but that is not
   a substitute for the isolated test suite.

The APK is suitable for a limited device test after installation is verified.

## Install on another Android device

Download the preview APK above from the workspace or its EAS build page,
transfer it to the device, open the file, and allow installation from that
source if Android asks. A previous debug build of `id.huni.app` uses a
different signing key and must be uninstalled first; uninstalling clears that
installation's local app data. The AAB is for Google Play and is not the file
to sideload.
