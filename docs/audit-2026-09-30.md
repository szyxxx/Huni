## Temuan yang diperbaiki di repo

1. Query katalog live gagal dengan PostgreSQL `42703`: `properties.virtual_tour_url` belum ada. Pembacaan katalog kini mengulang query tanpa dua kolom tur virtual hanya untuk kesalahan skema tersebut. Fitur tur tetap menunggu migrasi `0010`; kesalahan query lain tetap ditampilkan.
2. Respons AI Search divalidasi sebelum digunakan, dan pencarian baru mengatur ulang filter lama agar hasil tidak dipersempit secara tersembunyi.
3. URL tur virtual sebelumnya masuk langsung ke HTML/JavaScript WebView. URL kini harus HTTPS tanpa kredensial dan di-escape; tes mencakup payload injeksi.
4. Kebijakan insert `leads` awal mengizinkan siapa saja mengirim `user_id` orang lain. Migrasi `0011` membatasi insert ke pemilik akun terautentikasi. Migrasi ini **belum diterapkan** ke live.
5. Tombol jadwal tur tanpa nomor kontak yang dapat dihubungi dihapus. Sign-out yang gagal tidak lagi membuang workspace lokal. Peringatan lint dan ketidakcocokan patch Expo diperbaiki.
