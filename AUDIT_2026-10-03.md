# Audit Huni — 3 Oktober 2026

## Cakupan

- Git: `master` adalah satu-satunya branch lokal dan remote.
- Ditelusuri: route Expo, alur Beranda → Explore → detail → minat, Hunian Baru,
  Tersimpan, KPR, navigasi, peta, penyimpanan lokal, migrasi dan advisor Supabase.

  detail properti, dan lembar minat. iOS belum dapat diuji di host Windows ini.

## Batas yang masih ada

1. Keenam pengiklan belum punya `owner_id` dan `contact_phone`; dua proyek belum terhubung ke developer. Pengiriman minat sungguhan perlu data kontak atau akun developer resmi. Simulasi saat ini hanya tersimpan di perangkat.
2. Verifikasi visual Liquid Glass native di iOS 26+ memerlukan simulator/perangkat iOS. Build dan interaksi Android sudah diuji.
3. Tile OSM hanya menyediakan POI lokal pada zoom tinggi; pengguna perlu menggeser peta untuk menelusuri seluruh area 10 km. Ketergantungan ini perlu pemantauan jika trafik tumbuh.
4. `npm audit --omit=dev` melaporkan 32 advisory (21 high, 11 moderate). Semua saran `fixAvailable` meminta perubahan mayor yang menurunkan versi Expo/RN atau modul terkait; tidak dijalankan karena merusak kompatibilitas SDK 57. Perlu triase ulang ketika versi SDK yang kompatibel tersedia.
5. Tes RLS lokal `npm run test:db` belum dapat berjalan karena Docker Desktop tidak aktif. Skema, grant, policy, dan advisor diverifikasi langsung pada proyek Supabase.
6. Portal penjual/admin, data pengiklan asli, dan artefak rilis Play Store masih bergantung pada operasi produk di luar aplikasi.
7. Di pengaturan notifikasi, hanya pantau penurunan harga yang aktif; lima kategori lain masih dinonaktifkan karena alur pengiriman belum tersedia. Input suara pada pencarian tidak ditampilkan sampai benar-benar bisa dipakai.
